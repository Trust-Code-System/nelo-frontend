# Shop API schema

The Vendure **Shop API** SDL goes here as `shop-api.graphql`. Not the Admin API — the Admin
schema is generated by the backend's Dashboard build and is not the storefront's contract.

Two ways to supply it:

```bash
# a) commit an export
npx get-graphql-schema http://localhost:3000/shop-api > schema/shop-api.graphql

# b) point at a reachable endpoint instead
VENDURE_SCHEMA=http://localhost:3000/shop-api npm run codegen
```

Until one exists, `npm run codegen:check` reports **PENDING** and CI emits a warning
annotation on every run. It becomes an enforcing gate the moment the schema lands, with no
change to the workflow.

Generated output goes to `src/lib/vendure/generated/` and is **committed** so CI can diff it.
Never hand-edit it.
